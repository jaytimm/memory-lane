How to use Memory Lane

  1. Browse an album.Click an album picture. Its photographs will appear below.
  2. Browse by decade.Click a decade near the top. Click All years when you are finished.
  3. Search for something you remember.Type a short description such as yellow tents, hugs, or two smiling faces.
  4. See search ideas.Open the examples below the search box and click any example to run it.
  5. Open a photograph.Click it to enlarge it. Use the left and right arrows to move through the results.
  6. Find related photographs.Open a photograph and choose Find similar photos or Find this person.
  7. Copy or save a photograph.Right-click the photograph to use your browser’s normal Copy image or Save image as options. For full quality, open the original first.
  8. Start over.Click Show all photographs or Clear search and filters.
