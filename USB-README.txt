MEMORY LANE PHOTO USB
=====================

This drive contains two separate folders:

  Family Photos   The original photograph folders.
  Memory Lane     The gallery and search indexes.

ANY COMPUTER (Windows, Mac, or Chromebook)

1. Double-click "Open Memory Lane" at the top of this drive.
2. The gallery opens in your web browser. Wait a few seconds for
   "Ready to search" to appear below the search box.
3. Close the browser tab when finished, then safely eject the USB drive.

Memory Lane works locally and needs no internet connection. Photographs are
read from the Family Photos folder on this USB and are not uploaded.
"Go to original" opens the full-resolution USB photograph.

OLDER WINDOWS LAUNCHER (backup)

If the gallery does not open on a Windows computer, open the Memory Lane
folder and double-click "Start Memory Lane from USB.bat" instead. The first
start may take several minutes. Leave its black window open while using the
gallery.

Keep the Family Photos and Memory Lane folders together at the top level of the
drive. Renaming or moving either folder will prevent Memory Lane from finding
the photographs.
