MEMORY LANE PHOTO USB
=====================

This drive contains two separate folders:

  Family Photos   The original photograph folders.
  Memory Lane     The gallery, search indexes, and Windows launcher.

WINDOWS

1. Open the Memory Lane folder.
2. Double-click "Start Memory Lane from USB.bat".
3. The first start on a computer may take several minutes while the app is
   prepared. Later starts should be faster.
4. Leave the black Memory Lane window open while using the gallery.
5. Close that window when finished, then safely eject the USB drive.

Memory Lane works locally. Photographs are read from the Family Photos folder
on this USB and are not uploaded. "Go to original" opens the full-resolution
USB photograph in a fit-to-window browser view.

Keep the Family Photos and Memory Lane folders together at the top level of the
drive. Renaming or moving either folder will prevent the launcher from finding
the photographs.
