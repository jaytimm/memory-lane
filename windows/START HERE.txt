MEMORY LANE — START HERE
========================

This USB drive should contain two separate folders:

  Family Photos\
    The 45 original album folders and photographs only.

  Memory Lane\
    Gallery\
    MemoryLane-Windows-x64.zip
    Start Memory Lane from USB.bat
    START HERE.txt
    VERSION.txt

The photographs are copied first into Family Photos. The Memory Lane folder is
added afterward. Original photographs are never mixed with app files.

TO OPEN MEMORY LANE ON WINDOWS

1. Open the "Memory Lane" folder.
2. Double-click "Start Memory Lane from USB.bat".
3. The first start may take a few minutes while Windows prepares the app.
4. Memory Lane will open in the normal web browser.
5. Leave the small black terminal window open while using Memory Lane.
6. Close that terminal window when finished, then safely eject the USB drive.

Do not unzip MemoryLane-Windows-x64.zip.
Do not rename or separate these files.

Memory Lane runs locally. Photographs and searches are not uploaded to the
internet, and the app does not change or delete photographs.
