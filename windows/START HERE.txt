MEMORY LANE — START HERE
========================

This USB drive should contain:

  FamilyPhotoArchive\
  MemoryLane-Windows-x64.zip
  Start Memory Lane from USB.bat
  START HERE.txt
  VERSION.txt

The photographs and prepared photo archive are copied to the USB drive first.
The Memory Lane ZIP, launcher, and these two text files are then added beside the
FamilyPhotoArchive folder.

TO OPEN MEMORY LANE ON WINDOWS

1. Double-click "Start Memory Lane from USB.bat".
2. The first start may take a few minutes while Windows prepares the app.
3. Memory Lane will open in the normal web browser.
4. Leave the small black terminal window open while using Memory Lane.
5. Close that terminal window when finished, then safely eject the USB drive.

Do not unzip MemoryLane-Windows-x64.zip.
Do not rename or separate these files.

Memory Lane runs locally. Photographs and searches are not uploaded to the
internet, and the app does not change or delete photographs.
