FAMILY PHOTO ARCHIVE - WINDOWS SEARCH
=====================================

Keep these items together in the same folder:

  Start Family Gallery.bat
  WindowsSearch\
  FamilyPhotoArchive\

Double-click "Start Family Gallery.bat". A small terminal window remains open
while search is running. The gallery opens automatically in the default browser.

Closing the terminal stops semantic search. The ordinary gallery still works by
opening FamilyPhotoArchive\index.html directly.

All searches and photographs stay on this computer. Nothing is uploaded.
